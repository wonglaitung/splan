## 阅读路径建议

* **研发人员**：先读《AI 时代的提问哲学及科学纠偏指南》第一编（内环方法论），再读防翻车清单。
* **架构/安全**：金融 RAG 六篇 + 权限安全架构，配合指南第二编（对抗审核）落地。
* **审计/合规**：直接使用 templates 下的审核表、红队用例、合规清单与审计日志 Schema。
